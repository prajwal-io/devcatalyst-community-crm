# DevCatalyst visual direction

Use the supplied monochrome logo unmodified. Pair warm ivory surfaces with charcoal-green ink and restrained botanical accents. System fonts keep loading fast; a native serif accents the welcome headline. Shared React layouts unify account screens and the workspace. Keep motion brief and respect reduced-motion preferences. Preserve readable labels, visible keyboard focus, responsive forms, and all existing role-protected workflows. No additional UI libraries or external font services.
